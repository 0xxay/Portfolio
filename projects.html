Azure Sentinel Detection Engineering

Cloud-native SIEM detection rules with ML-based anomaly detection

Azure Sentinel KQL Python Machine Learning Log Analytics

Overview

Designed and deployed a detection engineering pipeline on Microsoft Sentinel to identify threats across cloud workloads. The project focused on writing high-fidelity KQL detection rules and augmenting them with machine learning-based anomaly detection to reduce false positives and surface real attacker behavior.

Key Highlights

  • Built 8+ custom KQL detection rules covering brute-force attempts, impossible travel, privilege escalation, and suspicious sign-in patterns
  • Implemented ML-based anomaly detection achieving 85%+ accuracy for identifying deviations from baseline behavior
  • Mapped every detection rule to MITRE ATT&CK tactics and techniques for coverage tracking
  • Configured automated incident creation and enrichment with entity mapping in Sentinel
  • Tuned alert thresholds iteratively to reduce false positives and analyst fatigue

Skills Demonstrated

KQL query development, Sentinel analytics rules, ML anomaly detection, MITRE ATT&CK mapping, alert tuning

SOC & Threat Hunting Platform

Enterprise SOC lab with real-time detections and hunting dashboards

Splunk Sysmon SPL MITRE ATT&CK Windows Event Logs

Overview

Built an enterprise-grade SOC lab environment from the ground up using Splunk Enterprise as the central SIEM. Endpoint telemetry was collected via Sysmon and Windows Event Logs, enabling realistic detection development and hands-on threat hunting exercises against simulated attacks.

Key Highlights

  • Designed and deployed 15+ SPL detection rules for credential dumping, lateral movement, persistence mechanisms, and suspicious process execution
  • Instrumented endpoints with Sysmon using a tuned configuration for high-value telemetry
  • Created real-time threat hunting dashboards visualizing authentication anomalies, process trees, and network connections
  • Simulated adversary techniques and validated detection coverage against the MITRE ATT&CK framework
  • Documented investigation playbooks for triage and incident response workflows

Skills Demonstrated

SPL query language, SIEM architecture, endpoint telemetry, threat hunting methodology, dashboard design

DevSecOps Pipeline on AWS

Secure CI/CD with automated scanning and Kubernetes deployment

AWS Docker Kubernetes (EKS) Trivy CodePipeline Bandit

Overview

Engineered an end-to-end DevSecOps pipeline on AWS that embeds security checks at every stage of the software delivery lifecycle — from static code analysis to container image scanning — before deploying workloads to a managed Kubernetes cluster.

Key Highlights

  • Built a CI/CD pipeline using AWS CodePipeline with automated build, test, and deploy stages
  • Integrated Bandit for static application security testing (SAST) of Python code
  • Added Trivy scanning to detect vulnerabilities in container images before they reach the registry
  • Stored hardened images in Amazon ECR and deployed to Amazon EKS with least-privilege IAM roles
  • Enforced security gates that fail the pipeline on critical vulnerability findings

Skills Demonstrated

CI/CD pipeline security, container vulnerability scanning, Kubernetes deployment, AWS IAM, shift-left security
